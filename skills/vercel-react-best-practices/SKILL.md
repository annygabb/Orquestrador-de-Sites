# Vercel React Best Practices

Revise o projeto React ou Next.js para identificar renderizações desnecessárias, carregamentos sequenciais e JavaScript excessivo. Priorize os problemas por impacto, explique as melhorias propostas e preserve o visual e as funcionalidades existentes. Não altere credenciais nem publique mudanças sem autorização.
