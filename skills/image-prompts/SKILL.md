# Prompts de Imagem para Sites

Colete nome da marca, iniciais, elemento visual, paleta, uso final e referências antes de escrever o prompt.

Para logos, solicite composição limpa, aparência vetorial, espaçamento equilibrado, fundo transparente e ausência de ornamentos ou estética genérica de IA.

Para hero com uma pessoa:

- preserve exatamente identidade, rosto, expressão, pose, roupa, cabelo e textura natural;
- crie uma versão horizontal própria para desktop e outra vertical 9:16 para celular;
- reserve espaço negativo real para o texto;
- mantenha contraste legível sem aplicar overlay sobre a pessoa;
- preserve iluminação, nitidez, proporções e tons naturais;
- evite filtros de beleza, suavização artificial, blur irreal e aparência de banco de imagens.

Informe no resultado a proporção, o enquadramento, a zona segura para texto, a cor do overlay e os elementos que não podem ser alterados.
